# POWER AUTOMATE AI / MACHINE BUILD SPECIFICATION

## Flow Identity

```yaml
flow_type: Instant cloud flow
flow_name: SP_Site_List_Column_Full_Audit
trigger: Manually trigger a flow
primary_connector: SharePoint
primary_http_action: Send an HTTP request to SharePoint
file_action: SharePoint Create file
purpose: Retrieve every SharePoint list/library returned by a site, log every list detail, every field/column, field type, internal name, static name, schema XML, and raw metadata payloads.
```

## Global Rules

```yaml
rules:
  - Do not filter hidden lists.
  - Do not filter system lists.
  - Do not filter document libraries.
  - Do not filter catalog lists.
  - Do not filter private lists.
  - Process every list returned by /_api/web/lists.
  - Store raw REST payloads as JSON files.
  - Store normalized searchable rows in the audit log list.
  - Use application/json;odata=verbose for all SharePoint REST calls.
  - Use dynamic ListItemEntityTypeFullName for all audit log item creation.
  - Use per-list error handling so one failed list does not stop the run.
  - Set Apply to each list concurrency to 1.
  - Apply exponential retry policy to every SharePoint HTTP action.
```

## Standard HTTP Headers

```json
{
  "Accept": "application/json;odata=verbose"
}
```

```json
{
  "Accept": "application/json;odata=verbose",
  "Content-Type": "application/json;odata=verbose"
}
```

## Retry Policy For Every SharePoint HTTP Action

```yaml
retry_policy:
  type: Exponential
  count: 4
  minimum_interval: PT20S
  maximum_interval: PT5M
```

  parent: DO_UNTIL_All_Lists_Retrieved

  parent: DO_UNTIL_All_Lists_Retrieved
  type: Apply to each
  input: "body('HTTP_Get_Lists_Page')?['d']?['results']"

- action_name: APPEND_List_To_AllLists
  parent: APPLY_Each_List_In_Page
  type: Append to array variable
  name: varAllLists
  value: "items('APPLY_Each_List_In_Page')"

- action_name: COND_Lists_Page_Has_Next
  parent: DO_UNTIL_All_Lists_Retrieved
  type: Condition
  expression: "not(empty(body('HTTP_Get_Lists_Page')?['d']?['__next']))"
  if_yes:
    action_name: SET_ListsNextUri_To_Next
    type: Set variable
    name: varListsNextUri
    value: "replace(body('HTTP_Get_Lists_Page')?['d']?['__next'], variables('varTargetSiteUrl'), '')"
  if_no:
    action_name: SET_ListsNextUri_To_Blank
    type: Set variable
    name: varListsNextUri
    value: ""

- action_name: FILE_Create_All_Lists_Summary_JSON
  type: Create file
  site_address: "variables('varTargetSiteUrl')"
  folder_path: "concat('/', variables('varAuditLibraryName'), '/', variables('varRunFolderPath'))"

# MODULE 21: Validation Checklist

```yaml
validation:
  - The manual trigger has TargetSiteUrl, AuditLibraryName, and AuditListName.
  - The audit document library is created with BaseTemplate 101.
  - The audit log list is created with BaseTemplate 100.
  - The audit log list has all required columns.
  - HTTP_Get_AuditLog_List_Metadata runs before audit row creation.
  - List retrieval uses /_api/web/lists?$top=5000 with pagination.
  - No returned list is intentionally filtered out.
  - Each list has its own folder under SiteInventory/<RunId>/lists/<ListTitle>_<ListId>.
  - Each list folder contains all raw JSON files.
  - Each list creates one List audit row.
  - Each returned field creates one Field audit row.
  - Per-list failures create error.json and an Error audit row.
  - The run creates errors-summary.json.
  - The final Run row status is Completed when there are no errors and Partial when errors exist.
```
