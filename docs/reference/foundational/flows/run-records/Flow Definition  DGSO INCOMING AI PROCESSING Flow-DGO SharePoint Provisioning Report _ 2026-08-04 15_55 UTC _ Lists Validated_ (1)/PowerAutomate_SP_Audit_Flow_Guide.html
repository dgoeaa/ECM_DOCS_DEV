1. AI / Machine Optimized Prompt for Power Automate Describe It

Copy this full prompt into Power Automate Copilot Describe it. After generation, review the created flow against the Action Build Order and Expressions sections below.

Complete Describe It Prompt

Create an instant cloud flow named SP_Site_List_Column_Full_Audit.
Trigger: Manually trigger a flow.
Trigger inputs:
1. TargetSiteUrl, Text, Required, description: Full SharePoint site URL to audit.
2. AuditLibraryName, Text, Required, default value: SP_Metadata_Audit_Logs.
3. AuditListName, Text, Required, default value: SP_Metadata_AuditLog.

Global requirements:
- Use the SharePoint connector action Send an HTTP request to SharePoint for all REST calls.
- Use the SharePoint Create file action for file creation.
- Do not filter hidden lists, system lists, document libraries, private lists, catalog lists, application lists, or any list returned by /_api/web/lists.
- Use application/json;odata=verbose for all REST responses.
- Use pagination for /_api/web/lists.
- Store raw JSON responses in the audit document library.
- Store searchable normalized run, list, field, and error rows in the audit log list.
- Use scopes for create-if-missing and per-list error handling.
- Set Apply to each list concurrency to On with degree of parallelism 1.
- Set retry policy on every Send an HTTP request to SharePoint action to exponential with count 4, minimum interval PT20S, and maximum interval PT5M.
- Use dynamic ListItemEntityTypeFullName for audit log item creation.

Initialize these variables in order:
INIT_TargetSiteUrl: string = triggerBody()?['text']
INIT_AuditLibraryName: string = triggerBody()?['text_1']
INIT_AuditListName: string = triggerBody()?['text_2']
INIT_RunId: string = formatDateTime(utcNow(),'yyyyMMddTHHmmssZ')
INIT_RunFolderPath: string = concat('SiteInventory/', variables('varRunId'))
INIT_ListsNextUri: string = /_api/web/lists?$top=5000
INIT_AllLists: array = []
INIT_Errors: array = []

Create combined JSON file final-combined-list-metadata.json with RunId, CapturedUtc, TargetSiteUrl, ListId, ListTitle, and the bodies of all per-list HTTP actions.
Create one list audit row with AuditRecordType=List and BaseTemplate, BaseType, Hidden, ItemCount from HTTP_Get_List_Details.
Apply to each body('HTTP_Get_List_Fields')?['d']?['results'] as APPLY_Each_Field. Create one audit row per field with all field detail expressions from the expression reference.
If SCOPE_Process_One_List fails or times out, run SCOPE_Log_List_Error. Append result('SCOPE_Process_One_List') to varErrors, create error.json in the list folder, and create an Error audit row.

See errors-summary.json.')), and RawJsonFilePath=concat(variables('varAuditLibraryName'), '/', variables('varRunFolderPath'), '/errors-summary.json').

2. Architecture

Input

Manual trigger inputs: TargetSiteUrl, AuditLibraryName, AuditListName.

Storage

Raw JSON files go into the audit document library. Searchable run, list, field, and error rows go into the audit log list.

Coverage

The flow logs every list returned by /_api/web/lists and every field returned by each list's Fields endpoint.

Error Handling

Each list is processed inside a scope. Failures create error.json and an Error row without stopping the entire audit.

3. Preliminaries

Permission requirement: Run the flow connection with Site Collection Admin or equivalent permissions so the REST calls can read lists, fields, views, role assignments, and library metadata.
  • Create an Instant cloud flow.
  • Add the three manual trigger inputs exactly as named in the prompt.
  • Use SharePoint Send an HTTP request to SharePoint for REST calls.
  • Use verbose JSON headers for complete audit capture.
  • Use dynamic ListItemEntityTypeFullName before creating audit list items.

4. Action Build Order

Initialize

Create varTargetSiteUrl, varAuditLibraryName, varAuditListName, varRunId, varRunFolderPath, varListsNextUri, varAllLists, and varErrors.

Site and Infrastructure

Get site metadata, check or create the audit library, check or create the audit log list, create required audit columns, and retrieve the dynamic audit list item entity type.

Folder and Run Start

Create SiteInventory, RunId, and lists folders. Create a Run Started audit row. Save site-metadata.json.

Retrieve Lists

Do until varListsNextUri is blank. Append every returned list object to varAllLists. Save all-lists-summary.json.

Process Lists

For each list, create list folder, get details, fields, content types, views, forms, root folder, role assignments, event receivers, user custom actions, workflow associations, default view, and save every payload as JSON.

Normalize Rows

Create one List audit row per list and one Field audit row per field. Preserve raw SchemaXml and raw JSON file paths.

Finish

Save errors-summary.json and create the Run Completed audit row with Completed or Partial status.

8. Validation Checklist

  • Audit library exists: SP_Metadata_Audit_Logs, unless a different trigger value is supplied.
  • Audit log list exists: SP_Metadata_AuditLog, unless a different trigger value is supplied.
  • HTTP_Get_AuditLog_List_Metadata runs before any audit item creation.
  • Apply to each list concurrency is set to 1.
  • Every Send an HTTP request action has Accept: application/json;odata=verbose.
  • all-lists-summary.json is created after pagination completes.
  • Every list folder contains fields.json and final-combined-list-metadata.json.
  • Each field row includes FieldInternalName, FieldTypeAsString, FieldTypeKind, and FieldSchemaXml.
