# Power Automate HTTP Flows — Phase C: Flow-Content Fidelity Reconciliation
## End-to-End Live Execution Runbook (Termux on Android)

Phase A (canonical build) and Phase B (per-folder merge) are closed: every retained byte is SHA-256-verified and every container is structurally intact. Phase C closes the **semantic** gap — proving that the flow inventories, endpoints, trigger schemas, response schemas, parameter contracts, and per-flow narratives across the retained corpus describe one coherent set of flows with no unresolved disagreements.

| Step | Purpose | Output |
|---:|---|---|
| C1 | Build flow × artefact coverage matrix from the candidate flow universe | `_phaseC/coverage_matrix.tsv` |
| C2 | Assign canonical authority per attribute axis | `_phaseC/authority_matrix.md` |
| C3 | Pairwise consistency diff across all coverage cells | `_phaseC/diff_report.md` |
| C4 | Log every disagreement as a defect with disposition | `_phaseC/defect_log.tsv` |
| C5 | Apply reconciliations + tombstone retired artefacts | `_phaseC/reconciliation_log.md` |
| C6 | Re-run canonical build + merge over reconciled content | new `Flows_Details_Canonical_SoT_<ts>/` |
| C7 | Issue signed Fidelity Determination + re-audit | `_phaseC/FIDELITY_DETERMINATION.md` |

Phase C is **additive** to the canonical folder; nothing from Phase A or B is deleted until C7 exits cleanly.

CANON = os.environ["CANON_DIR"]

import os, json, hashlib

try:
    with open(ref) as f: r = json.load(f)
    ref_keys = set()
    def walk(o):
        if isinstance(o, dict):
            for k,v in o.items():
                ref_keys.add(k.lower())
                walk(v)
        elif isinstance(o, list):
            for x in o: walk(x)
    walk(r)
except Exception as e:
    ref_keys = set()
    print(f"\n> WARNING: could not parse reformatted package: {e}\n")
for fn in sorted(os.listdir(sd)):

    base = os.path.splitext(fn)[0].lower()

PY
