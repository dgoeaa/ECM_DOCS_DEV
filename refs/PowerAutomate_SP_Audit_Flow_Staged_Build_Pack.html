Power Automate SharePoint Audit Flow: Staged Build Pack

Use this when Describe it returns No flow suggestions. The full design is too complex for the preview natural-language generator, so this pack breaks it into smaller scaffold prompts and provides a manual fallback.

Why the earlier prompt failed

The Describe it feature is a preview capability. Microsoft documents it as a natural-language flow creation feature that generates suggested flows, but if a suggestion does not match or cannot be produced, the user must adjust or continue in the designer. It also depends on supported environments and available connector/action coverage.

1. Staged Describe It Prompts

Use one stage at a time. If a stage fails, create the action manually and continue with the next stage.

Stage 1 - Scaffold only
Create an instant cloud flow named SP_Site_List_Column_Full_Audit. Use a manual trigger with three text inputs named TargetSiteUrl, AuditLibraryName, and AuditListName. Initialize variables varTargetSiteUrl from triggerBody()?['text'], varAuditLibraryName from triggerBody()?['text_1'], varAuditListName from triggerBody()?['text_2'], varRunId from formatDateTime(utcNow(),'yyyyMMddTHHmmssZ'), varRunFolderPath from concat('SiteInventory/', variables('varRunId')), varListsNextUri with /_api/web/lists?$top=5000, varAllLists as an empty array, and varErrors as an empty array. Add a SharePoint Send an HTTP request to SharePoint action named HTTP_Get_Site_Metadata using Site Address variables('varTargetSiteUrl'), Method GET, Uri /_api/web, and header Accept application/json;odata=verbose.
Stage 2 - Create audit infrastructure
Continue the flow. Add a SharePoint Send an HTTP request to SharePoint action named HTTP_Check_Audit_Library. Site Address variables('varTargetSiteUrl'), Method GET, Uri concat('/_api/web/lists/GetByTitle(''', variables('varAuditLibraryName'), ''')'), header Accept application/json;odata=verbose. Add a scope named SCOPE_Create_Audit_Library_If_Missing that runs after HTTP_Check_Audit_Library has failed or timed out. Inside it add HTTP_Create_Audit_Library with Method POST, Uri /_api/web/lists, headers Accept application/json;odata=verbose and Content-Type application/json;odata=verbose, body creating an SP.List with BaseTemplate 101 and Title @{variables('varAuditLibraryName')}. Add HTTP_Check_AuditLog_List similarly for variables('varAuditListName'). Add SCOPE_Create_AuditLog_List_If_Missing that creates an SP.List with BaseTemplate 100 and Title @{variables('varAuditListName')}.
Stage 3 - Add audit log columns
Continue the flow. Inside SCOPE_Create_AuditLog_List_If_Missing, add SharePoint Send an HTTP request to SharePoint actions that POST to concat('/_api/web/lists/GetByTitle(''', variables('varAuditListName'), ''')/Fields/CreateFieldAsXml'). Use headers Accept application/json;odata=verbose and Content-Type application/json;odata=verbose. Add fields RunId, AuditRecordType, TargetSiteUrl, ListId, ListTitle, ListBaseTemplate, ListBaseType, ListHidden, ItemCount, FieldId, FieldTitle, FieldInternalName, FieldStaticName, FieldTypeAsString, FieldTypeDisplayName, FieldTypeKind, FieldRequired, FieldHidden, FieldReadOnly, FieldIndexed, FieldEnforceUniqueValues, FieldGroup, FieldDescription, FieldSchemaXml, RawJsonFilePath, CaptureUtc, AuditStatus, and ErrorMessage. Use CreateFieldAsXml with SP.XmlSchemaFieldCreationInformation and Options 0.
Stage 4 - Folders and run-start row
Continue the flow. Add HTTP_Get_AuditLog_List_Metadata using Method GET and Uri concat('/_api/web/lists/GetByTitle(''', variables('varAuditListName'), ''')?$select=ListItemEntityTypeFullName'). Create folders by POSTing to /_api/web/folders with ServerRelativeUrl values built from body('HTTP_Get_Site_Metadata')?['d']?['ServerRelativeUrl'], variables('varAuditLibraryName'), and variables('varRunFolderPath'). Create SiteInventory, the run folder, and the lists folder. Then create a run-start item in the audit log list using POST concat('/_api/web/lists/GetByTitle(''', variables('varAuditListName'), ''')/items') and use __metadata.type from body('HTTP_Get_AuditLog_List_Metadata')?['d']?['ListItemEntityTypeFullName'].
Stage 5 - List pagination
Continue the flow. Add a Do until action named DO_UNTIL_All_Lists_Retrieved with condition equals(variables('varListsNextUri'), ''). Set count limit 500 and timeout PT1H. Inside it call HTTP_Get_Lists_Page using GET variables('varListsNextUri') and header Accept application/json;odata=verbose. Add Apply to each named APPLY_Each_List_In_Page over body('HTTP_Get_Lists_Page')?['d']?['results'] and append each item to varAllLists. Add a condition not(empty(body('HTTP_Get_Lists_Page')?['d']?['__next'])); if true set varListsNextUri to replace(body('HTTP_Get_Lists_Page')?['d']?['__next'], variables('varTargetSiteUrl'), ''), otherwise set varListsNextUri to blank. After the loop create all-lists-summary.json in the run folder with content string(variables('varAllLists')).
Stage 6 - Process every list
Continue the flow. Add Apply to each named APPLY_Each_List over variables('varAllLists') and set concurrency degree to 1. Compose CMP_ListId as items('APPLY_Each_List')?['Id'], CMP_ListTitle as items('APPLY_Each_List')?['Title'], CMP_SafeListTitle using nested replace for /, backslash, colon, star, question mark, double quote, less than, greater than, pipe, and #, and CMP_ListFolderRelative as concat(variables('varRunFolderPath'), '/lists/', outputs('CMP_SafeListTitle'), '_', outputs('CMP_ListId')). Create the list folder. Inside SCOPE_Process_One_List call list details, fields, content types, views, forms, root folder, role assignments, event receivers, user custom actions, workflow associations, and default view REST endpoints. Save each response to a matching JSON file. Create one list audit row and one field audit row for every item in body('HTTP_Get_List_Fields')?['d']?['results']. Add SCOPE_Log_List_Error configured to run after SCOPE_Process_One_List has failed or timed out.
Stage 7 - Completion
Continue the flow. After APPLY_Each_List, create errors-summary.json in the run folder with content string(variables('varErrors')). Create a run-completed item in the audit log list with AuditRecordType Run, AuditStatus if(equals(length(variables('varErrors')), 0), 'Completed', 'Partial'), ErrorMessage if(equals(length(variables('varErrors')), 0), '', concat(string(length(variables('varErrors'))), ' list-level errors occurred. See errors-summary.json.')), and RawJsonFilePath concat(variables('varAuditLibraryName'), '/', variables('varRunFolderPath'), '/errors-summary.json').

2. Manual Fallback Path

Manual route when Describe it fails

If Power Automate Describe it returns No flow suggestions, use this route:
1. Create the instant flow manually.
2. Add the trigger and variables.
3. Create the audit library and audit list with Send an HTTP request to SharePoint.
4. Add the column creation REST actions.
5. Add the pagination loop.
6. Add the list processing loop.
7. Add the error scope and completion row.
This works because the designer supports these actions even when the natural-language preview generator does not scaffold them.
