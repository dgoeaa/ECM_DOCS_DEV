Architecture

Persistence Architecture

The persistence model separates user enrollment, RBAC, role history, audit, pending writes, departments, access scopes, pilot cohorts, endpoint registry and access diagnostics into dedicated SharePoint lists. This retains clear ownership and operational traceability per platform function.

Provisioning

Manifest-Driven Power Automate Flow

  1. Upload dgo-sharepoint-schema.json to Shared Documents/DGO-Provisioning/dgo-sharepoint-schema.json.
  2. Create flow DGO_PROVISION_SHAREPOINT_SCHEMA_FROM_MANIFEST.
  3. Read manifest by file path.
  4. Parse JSON using dgo-manifest-parse-json-schema.json.
  5. Create all lists if missing.
  6. Create all fields if missing, with field-loop concurrency set to 1.
  7. Create all seed records if missing.
  8. Validate all DGO_ lists exist.
